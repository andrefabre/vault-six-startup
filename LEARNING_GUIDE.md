# Learning Guide - Digital Asset Security Application

## Introduction
This guide provides a structured approach to learning Django development through the Digital Asset Security application. Each module builds upon the previous one, creating a comprehensive learning experience.

## Module 1: Django Testing Fundamentals
Currently in progress! This module covers:

### Unit Testing Basics
1. Test Structure
   - Test cases and methods
   - setUp and tearDown
   - Assertions and expectations

2. Test Types
   - Model tests
   - Form tests
   - View tests
   - Integration tests

3. Test Tools
   - pytest and pytest-django
   - coverage.py
   - Test client

### Hands-on Exercises
1. Fix the failing tests in GitHub issues:
   - Form validation tests
   - View redirect tests
   - Model string representation tests

2. Write new tests for:
   - Edge cases in forms
   - Permission checks
   - File upload validation

### Learning Objectives
- Understand Django's testing framework
- Write effective test cases
- Use test coverage tools
- Practice test-driven development

### Resources
- Django Testing Documentation
- pytest Documentation
- Code Coverage Best Practices
